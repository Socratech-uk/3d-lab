Model requirements & setup ↗

Front is the main reference. Add matching Left, Back or Right images of the same object. This engine supports these four views; top and bottom are not inputs. Select Hunyuan3D 2 multiview for this workflow.

Automatic chooses an available device. CPU generation can take much longer.

Tight framing gives the object more of the model’s input image. Compare with the same seed; it can alter the shape and does not guarantee straight edges.

384 / 512 sample finer geometry; they do not add textures. CPU offload uses system RAM while keeping inference on NVIDIA GPU. Smaller decode batches can reduce memory use; larger grids still need more memory. Settings are saved with each generation.
